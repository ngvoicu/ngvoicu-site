### The Enhanced Forge Flow

This is the delivery loop I teach. One model writes the spec with you. Then one to four other models review it, each in a fresh session, from the same model family or a different one. The author model gets the best critiques back, and you implement only what you and the author model agree on. The code goes through the same review.
