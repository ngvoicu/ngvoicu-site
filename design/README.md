# design

The source artwork behind the site's look, and the options that were tried along the way. The site itself serves
smaller files made from these. Nothing here is linked from a page or listed in the sitemap.

A file ending in `-raw.png` is the untouched output of the image generator; the file with the same name and no `-raw`
is that picture after cleaning up. For the watercolour paintings in `consulting/`, `work/` and `about/` that means a
pure-white border and an exact 1600 × 1200 (the raw files are 1448 × 1086).

## Status

| Status | Meaning |
|---|---|
| **In use** | The site is built from it today. |
| **Earlier choice** | Was the pick at one point; replaced by a later one. |
| **Not chosen** | An option that was compared and not picked. |
| **Rejected** | Dropped early, before the options were compared. |
| **Raw** | The untouched generator output of the file named beside it. |
