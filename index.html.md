## Consulting

I help engineering teams start building software with coding agents. My talks and workshops go from “what is an LLM?” all the way to AI-native companies, software factories and AgentOS. I also run hands-on training for developers, and I can join a team and set it up in their own repositories: instruction files for the agents, a first spec, a shared knowledge base, review gates, and the security guardrails to run agents safely. I work on-site or remotely.
